*Version*: 1.9.0 *Status*: Stable / Maintenance *Last Updated*:

=== Project Overview

Aletheia is a zero-dependency Rust tool for verifying Rhodium Standard
Repository (RSR) compliance. Also serves as precursor research for
reversible operating systems (r-Minix).

=== Completion Status

* *Main Application* (`+src/main.rs+`)

** Zero dependencies

** 100% test pass rate
** RSR v2 offline-subset verification (26 checks: 13 Bronze, 12 Silver, 1 Gold)
** CLI with human, JSON, SARIF, HTML, badge, quiet, verbose output + `.aletheia.toml` config
