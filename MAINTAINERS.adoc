== Current Maintainers

* *Jonathan D.A. Jewell* — Project Lead — j.d.a.jewell@open.ac.uk

== Responsibilities

Maintainers review pull requests, triage issues, cut releases, and uphold
the project's security and conduct policies.

== Becoming a Maintainer

Maintainers are invited based on sustained, constructive contribution.

== Decision Making

[cols="1,2"]
|===
|Minor change |one maintainer approval
|Major change |consensus among maintainers
|Security fix |one maintainer approval, expedited
|===
