== Quick Start

[source,bash]
----
# Build (offline — nothing is downloaded)
just build

# Test
just test

# Verify RSR compliance
just verify
----

This project is *standalone by construction*: the scaffold fetches nothing,
the build has no external dependencies, and the licence texts ship in-tree
under `+LICENSES/+`.

== RSR Compliance
